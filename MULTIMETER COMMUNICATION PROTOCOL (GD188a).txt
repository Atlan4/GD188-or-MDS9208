===============================================================================
               MEASUREMENT CHIP COMMUNICATION PROTOCOL (GD188a)
===============================================================================

1. GENERAL PACKET STRUCTURE
-------------------------------------------------------------------------------
Communication operates asynchronously over a UART interface at regular 200 ms 
intervals (polling). Every valid data packet is finalized with a checksum byte.

Checksum (CS) Formula:
Checksum = (Sum of all packet bytes except the last one) % 256

2. INITIALIZATION HANDSHAKE (POWER-ON / ROTARY SWITCH TURNING)
-------------------------------------------------------------------------------
Step 1: Greeting from Chip   -> Chip sends: A0 01 A1 (A0+01 = CS A1)
Step 2: Set Function Mode    -> STM32 sends: 58 [MODE_HEX] [CS]
                             -> Chip responds: 58 [MODE_HEX] [CS] (Echo/Acknowledge)
Step 3: Force Autorange      -> STM32 sends: 5A 5A
                             -> Chip responds: 5A 00 5A (Autorange lock)

System state switches to: INIT_STEP_READY. The multimeter begins measuring.

3. HARDWARE HEX COMMANDS REFERENCE (STM32 -> CHIP)
-------------------------------------------------------------------------------
* Voltage Measurement (V / mV scales):
  - CMD_CHIP_6V_DC      = 0x05  -> Packet on UART: 58 05 5D
  - CMD_CHIP_6V_AC      = 0x06  -> Packet on UART: 58 06 5E
  - CMD_CHIP_600mV_DC   = 0x01  -> Packet on UART: 58 01 59
  - CMD_CHIP_600mV_AC   = 0x02  -> Packet on UART: 58 02 5A

* Current Measurement (uA / mA / 10A scales):
  - CMD_CHIP_uA_DC      = 0x0C  -> Packet on UART: 58 0C 64
  - CMD_CHIP_uA_AC      = 0x0D  -> Packet on UART: 58 0D 65
  - CMD_CHIP_mA_DC      = 0x0E  -> Packet on UART: 58 0E 66
  - CMD_CHIP_mA_AC      = 0x0F  -> Packet on UART: 58 0F 67
  - CMD_CHIP_10A_DC     = 0x10  -> Packet on UART: 58 10 68
  - CMD_CHIP_10A_AC     = 0x11  -> Packet on UART: 58 11 69

* Combined & Other Functions:
  - CMD_CHIP_RES        = 0x07  -> Resistance (Ohm)
  - CMD_CHIP_CONT       = 0x09  -> Continuity (Beeper)
  - CMD_CHIP_DIODE      = 0x0A  -> Diode Testing
  - CMD_CHIP_CAP        = 0x0B  -> Capacitance (Cx)
  - CMD_CHIP_HZ / PCT   = 0x12  -> Frequency / Duty Cycle

* Action commands from soft-touch buttons:
  - CMD_CHIP_AUTO       = 0x5A  -> Forces fully automatic range mode
  - CMD_CHIP_MANUAL     = 0x5B  -> F4 Button (RNG) - Cycles manual ranges
  - Request Data (Poll) = 0x60  -> STM32 sends 60 60 every 200 ms when READY

4. TELEMETRY PACKETS STRUCTURE (CHIP -> STM32)
-------------------------------------------------------------------------------
A. Standard Data Frame (0x60) - Length: 6 Bytes (V, mV, uA, mA, Ohm):
   Byte 0: 0x60 (Header)
   Byte 1: RAW_VALUE_LOW (Lower 8-bits of the measured value)
   Byte 2: RAW_VALUE_HIGH (Upper 8-bits of the measured value)
   Byte 3: STATUS_FLAGS (AC/DC flags, signs, indicators)
   Byte 4: RANGE_INDEX (Ranging byte used for decimal point scaling)
   Byte 5: CHECKSUM (Sum of Byte 0 to Byte 4)

B. Manual Range Response (0x5B) - Length: 3 Bytes (returned after pressing F4):
   Byte 0: 0x5B (Manual mode acknowledgment header)
   Byte 1: RANGE_INDEX (The specific range index the chip hopped to)
   Byte 2: CHECKSUM

C. Capacitance Frame (0x61)  - Length: 7 Bytes
D. Frequency Frame (0x62) - Length: 4 Bytes

5. DECIMAL POINTS MAPPING & DISPLAY MASKS (LINE 45 OF THE LCD)
-------------------------------------------------------------------------------
Layout scaling and decimal dot positions are driven strictly by MeasChip.range:

* Large Voltage Mode (V):
  - Index 0 -> Mask: 600.0 mV (Dot behind 3rd digit, indicator jumps to mV)
  - Index 1 -> Mask: 6.000 V  (Dot behind 1st digit)
  - Index 2 -> Mask: 60.00 V  (Dot behind 2nd digit)
  - Index 3 -> Mask: 600.0 V  (Dot behind 3rd digit)
  - Index 4 -> Mask: 1000 V   (No decimal dot)

* Small Voltage Mode (mV):
  - Index 0 -> Mask: 60.00 mV (Dot behind 2nd digit)
  - Index 1 -> Mask: 600.0 mV (Dot behind 3rd digit)

* Microcurrent Mode (uA):
  - Index 0 -> Mask: 600.0 uA (Dot behind 3rd digit)
  - Index 1 -> Mask: 6000 uA  (No decimal dot)

* Millicurrent Mode (mA):
  - Index 0 -> Mask: 60.00 mA (Dot behind 2nd digit)
  - Index 1 -> Mask: 600.0 mA (Dot behind 3rd digit)

* Heavy Current Mode (10A):
  - Index 0 -> Mask: 6.000 A  (Dot behind 1st digit, chip returns range 0x00)
  - Index 1 -> Mask: 10.00 A  (Dot behind 2nd digit, chip returns range 0x01)
